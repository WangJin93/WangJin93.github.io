Transcription Factor Target Finder (TFTF)

An R package for predicting transcription factor target genes and upstream transcription factors of target genes by bridging multiple predictive models and TF-target interaction databases.

📦 R Package 👤 Author: Jin Wang 📧 jin.wang93@outlook.com 🌐 Website

1. Introduction

Transcription Factor Target Finder (TFTF) is an R package designed for predicting transcription factor target genes and predicting upstream transcription factors of target genes. There are currently many online tools for predicting transcription factor target genes, such as hTFTarget, KnockTF, CHEA, TRRUST, GTRD, and ChIP Atlas, which are based on Chip-seq high-throughput data, transcriptional profiling data from knockdown/knockout experiments, or motif sequences.

Our aim is to fully utilize the prediction results from these online tools and combine them with correlation analysis to maximize the reliability of the predicted transcription factor-target gene regulatory relationships.

Key Features

  • Multiple Database Integration: Combines predictions from 9 different TF-target databases
  • Motif-Based Prediction: Uses FIMO and PWMEnrich for motif analysis
  • Correlation Analysis: Leverages TCGA, GTEx, and CCLE for expression correlation
  • Interactive Shiny App: User-friendly web interface for all analysis functions
  • 1575 Transcription Factors: Comprehensive coverage of human TFs (present in ≥2 datasets)

GitHub: https://github.com/WangJin93/TFTF
Shiny App: https://jingle.shinyapps.io/TF_Target_Finder/
Documentation: https://www.jingege.wang

2. Related Online Tools and Database Information

TFTF integrates data from the following authoritative transcription factor databases and tools:

Dataset Description
hTFtarget This database aggregates data from various transcription factor regulation studies, including experimental evidence and prediction results of transcription factor-target gene relationships.
KnockTF KnockTF is based on data from transcription factor knockout experiments, providing information on the regulation of gene expression by transcription factors.
ENCODE The ENCODE project provides extensive genomic functional annotation data, including transcription factor binding sites, chromatin accessibility regions, and gene regulatory elements.
CHEA The CHEA database offers transcription factor-target gene relationships based on shared promoter sequences, supporting enrichment analysis and construction of transcriptional regulatory networks.
TRRUST TRRUST curates a large amount of transcription factor-target gene interaction data from literature, providing reliable information on transcription factor regulation relationships.
GTRD GTRD collects transcription factor binding site data from ChIP-seq experiments, providing information on transcription factor binding in the genome.
ChIP_Atlas ChIP-Atlas integrates a large amount of publicly available ChIP-seq data, providing information on transcription factor binding sites and regulation in different cells and tissues.
JASPAR JASPAR is an authoritative transcription factor binding site database, providing binding sequence data for various species, used for predicting transcription factor DNA binding preferences and regulatory effects.
TCGA The Cancer Genome Atlas (TCGA) is a global collaborative project aimed at advancing cancer research and diagnosis by analyzing genomic, epigenomic, and clinical data from various cancer samples.
GTEx The Genotype-Tissue Expression (GTEx) project is a comprehensive research initiative aimed at exploring patterns and variations in gene expression across various human tissues.
CCLE The Cancer Cell Line Encyclopedia (CCLE) is a rich resource database providing molecular characterization data from various cancer cell lines.

4. Algorithm for Predicting Transcription Factor Target Genes Based on Motif

4.1 FIMO

FIMO (Find Individual Motif Occurrences) is a tool used to identify individual motif occurrences within DNA sequences, enabling the recognition of transcription factor binding sites and other functional DNA elements.

4.2 PWMEnrich

PWMEnrich (Position Weight Matrix Enrichment Analysis) is an R package for analyzing the enrichment of features such as promoter regions and transcription factor binding sites in genomic sequence data, utilizing a Position Weight Matrix (PWM) model for the identification and quantification of transcription factor binding sites.

6. Function Reference

6.1 predict_target

Description

Predict the target genes of Transcription Factor in multiple TF-target prediction databases and correlation analysis.

Usage

predict_target(
  datasets = c("hTFtarget", "KnockTF", "FIMO_JASPAR", "PWMEnrich_JASPAR", "ENCODE",
              "CHEA", "TRRUST", "GTRD", "ChIP_Atlas"),
  tf = "STAT3",
  TCGA_tissue = "COAD",
  GTEx_tissue = "Colon",
  cor_DB = c("TCGA", "GTEx"),
  cor_cutoff = 0.3,
  FIMO.score = 10,
  PWMEnrich.p = 0.1,
  cut.log2FC = 1,
  down.only = T,
  app = F
)

Arguments

ArgumentDescription
datasetsTF-target prediction databases to use (9 available)
tfTranscription factor name
TCGA_tissueTCGA tissue type for correlation analysis
GTEx_tissueGTEx tissue type for correlation analysis
cor_DBCorrelation databases: TCGA, GTEx, or CCLE
cor_cutoffCorrelation coefficient threshold (default: 0.3)
FIMO.scoreFIMO score threshold (default: 10)
PWMEnrich.pPWMEnrich p-value threshold (default: 0.1)
cut.log2FCLog2 fold change threshold for KnockTF (default: 1)
down.onlyOnly include downregulated genes from KnockTF

6.2 predict_TF

Description

predict_TF(

  TCGA_tissue = "COAD",
  GTEx_tissue = "Colon",
  cor_DB = c("TCGA", "GTEx"),

  FIMO.score = 10,
  PWMEnrich.p = 0.1,
  cut.log2FC = 1,
  down.only = T,
  app = F

Arguments

ArgumentDescription

Other argumentsSame as predict_target()

6.5 pantissue_cor_analysis

Description

Correlation analysis between TF and target gene in pan-tissue in "TCGA", "GTEx" or "CCLE" databases.

Usage

cor_results <- pantissue_cor_analysis(
  Gene1 = "FOXM1",
  Gene2 = "GAPDH",
  data_source = "TCGA",
  type = c("normal", "tumor"),
  cor_method = "pearson"
)

Arguments

ArgumentDescription
Gene1First gene symbol (e.g., TF)
Gene2Second gene symbol (e.g., target gene)
data_sourceDatabase: "TCGA", "GTEx", or "CCLE"
typeSample type: "normal", "tumor", or both
cor_methodCorrelation method: "pearson" or "spearman"

7. Shiny App Introduction

The R package has a built-in Shiny app that can implement all the functions of the R package. Required packages: shiny, DT, graph, ggraph, shinyWidgets, bs4Dash, tidygraph.

7.1 Launch the App

TFTF_app()

Or access the app online: https://jingle.shinyapps.io/TF_Target_Finder/

7.2 Module 1: Prediction of Target Genes of TF

This systematic approach enables a thorough analysis of TF-target gene interactions. The procedural steps are:

  • Input a TF name: Select a TF of interest from a dropdown list
  • Select TF-Target datasets: Choose the TF-Target datasets to include in the analysis
  • Select correlation datasets: Optionally enhance accuracy based on correlation analysis
  • Results: View prediction outcomes on the "All results" tab
  • Intersection selection: Select well-predicted datasets for intersection analysis
  • Visualize intersections: View Venn or petal diagrams

7.3 Module 2: Prediction of Upstream TFs of Target Genes

Similar to Module 1, but predicts upstream TFs for a given target gene:

  • Input a target gene symbol: Such as GAPDH
  • Select datasets: Choose predictive tools to include in the analysis
  • Correlation datasets: Optionally enhance accuracy with correlation analysis
  • Results: View and download detailed information for each tool's predictions

7.4 Module 3: Pan-tissue Correlation Analysis

Analyze expression correlation of TF-target pairs across various tissue types:

  • TF and target gene input: Select a transcription factor and enter the target gene
  • Database selection: Choose from TCGA, GTEx, and CCLE
  • Correlation parameters: Set analysis method and thresholds
  • Results: View correlation results and scatter plots
  • Detailed plots: Click on results to view detailed scatter plots

7.5 Module 4: TF-targets Regulation Network Analysis

Predict target genes based on user-uploaded differential expression results and visualize regulatory networks:

  • Data upload: Upload gene differential expression analysis results
  • Database selection: Choose TF-target prediction databases
  • Network visualization: Visualize the regulatory network
