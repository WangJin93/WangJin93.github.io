PCAS - CPTAC Proteomics & Transcriptome Data Analysis

An integrated tool for multi-dimensional cancer research utilizing Clinical Proteomic Tumor Analysis Consortium (CPTAC) data.

📦 Version: 0.1.0 👤 Author: Jin Wang 📧 Maintainer: jin.wang93@outlook.com 📅 Date: 2024-06-19

1. Introduction

PCAS (Proteomics & Transcriptome Cancer Analysis Suite) is an R package designed for comprehensive analysis and visualization of CPTAC proteomics and transcriptome data. This tool enables researchers to perform differential expression analysis, correlation analysis, drug sensitivity analysis, and immune infiltration analysis.

PCAS integrates data from multiple CPTAC cohorts and provides a user-friendly Shiny application for interactive visualization. It is ideal for researchers studying cancer proteomics and seeking to explore the relationship between protein expression and clinical outcomes.

Features

  • Access to CPTAC proteomics and transcriptome data
  • Differential expression analysis between tumor and normal samples
  • Correlation analysis of mRNA/protein expression data
  • Drug sensitivity analysis
  • Immune cell infiltration analysis
  • Interactive Shiny application

Dependencies

Imports: dplyr, drawProteins, ggplot2, jsonlite, psych, reshape2, shiny, tibble, ggpubr, ggrepel

GitHub: https://github.com/WangJin93/PCAS
Shiny App: https://jingle.shinyapps.io/PCAS/
Article: https://doi.org/10.3390/ijms25126690

2. Installation

You can install PCAS from GitHub using the remotes package:

remotes::install_github("WangJin93/PCAS")

To run the Shiny application:

library(PCAS)
PCAS_app()

4. Function Reference

4.1 get_data

Description

Get the CPTAC data by using the API. All results are saved in MySQL database.

Usage

get_data(
  table = "LUAD_Academia_protein",
  action = "expression",
  genes = c("GAPDH", "TNS1")
)

Arguments

ArgumentDescription
tableFor action = expression, use dataset$Abbre to get all tables; For action = clinic, remove _protein/_mRNA/_Phospho from dataset$Abbre.
action"expression", "degs" or "clinic".
genesGene symbols, you can input one or multiple symbols.

Examples

data <- get_data(table = "LUAD_Academia_protein", action = "expression", genes = c("GAPDH"))
data <- get_data(table = "LUAD_Academia", action = "clinic", genes = NULL)
4.2 get_expr_data

Description

Get the mRNA/protein expression data in CPTAC database.

Usage

get_expr_data(
  datasets = c("LUAD_CPTAC_protein", "LSCC_CPTAC_protein"),
  genes = c("TP53", "TNS1")
)

Arguments

ArgumentDescription
datasetsDataset names, you can input one or multiple datasets. Use 'dataset$Abbre' to get all datasets.
genesGene symbols, you can input one or multiple symbols.

Examples

data <- get_expr_data(datasets = "LUAD_CPTAC_protein", genes = c("TP53", "TNS1"))
data <- get_expr_data(datasets = c("LUAD_CPTAC_protein", "LSCC_CPTAC_protein"), genes = "GAPDH")
4.3 get_DEGs_result

Description

Get the results of differential expression analysis between tumor and normal samples in CPTAC datasets.

Usage

get_DEGs_result(dataset = "LUAD_CPTAC_protein", method = "t.test")

Arguments

ArgumentDescription
datasetUse dataset$Abbre to get all tables.
method"limma" or "t.test".

Examples

results <- get_DEGs_result(dataset = "LUAD_CPTAC_protein", method = "t.test")
results <- get_DEGs_result(dataset = "LUAD_CPTAC_protein", method = "limma")
4.4 merge_clinic_data

Description

Get clinic data and merge it with expression data.

Usage

merge_clinic_data(cohort = "LUAD_APOLLO", data_input)

Arguments

ArgumentDescription
cohortData cohort, for example, "LUAD_APOLLO", "LUAD_CPTAC".
data_inputExpression data obtained from get_expr_data() function.

4.5 cor_cancer_genelist

Description

Perform correlation analysis of the mRNA/protein expression data in CPTAC database.

Usage

cor_cancer_genelist(
  dataset1 = "LUAD_CPTAC_protein",
  id1 = "STAT3",
  dataset2 = "LUAD_CPTAC_mRNA",
  id2 = c("TNS1", "TP53"),
  sample_type = c("Tumor", "Normal"),
  cor_method = "pearson"
)

Arguments

ArgumentDescription
dataset1Dataset name. Use 'dataset$Abbre' to get all datasets.
id1Gene symbol, you can input one gene symbol.
dataset2Dataset name. Use 'dataset$Abbre' to get all datasets.
id2Gene symbols, you can input one or multiple symbols.
sample_typeSample type used for correlation analysis, default all types: c("Tumor", "Normal").
cor_methodMethod for correlation analysis, default "pearson".

Examples

results <- cor_cancer_genelist(
  dataset1 = "LUAD_CPTAC_protein",
  id1 = "STAT3",
  dataset2 = "LUAD_CPTAC_mRNA",
  id2 = c("TNS1", "TP53"),
  sample_type = c("Tumor", "Normal"),
  cor_method = "pearson"
)
4.6 cor_pancancer_genelist

Description

Perform correlation analysis of the mRNA/protein expression data in CPTAC database across multiple datasets.

Usage

cor_pancancer_genelist(
  df,
  geneset_data,
  sample_type = c("Tumor", "Normal"),
  cor_method = "pearson"
)

Arguments

ArgumentDescription
dfThe expression data of the target gene in multiple datasets, obtained by the get_expr_data() function.
geneset_dataThe expression data of a genelist in multiple datasets, obtained by the get_expr_data() function.
sample_typeSample type used for correlation analysis, default all types: c("Tumor", "Normal").
cor_methodMethod for correlation analysis, default "pearson".

Examples

target_data <- get_expr_data(datasets = c("LUAD_CPTAC_protein", "LSCC_CPTAC_protein"), genes = "STAT3")
gene_list_data <- get_expr_data(datasets = c("LUAD_CPTAC_protein", "LSCC_CPTAC_protein"), genes = c("TNS1", "TP53"))
results <- cor_pancancer_genelist(df = target_data, geneset_data = gene_list_data)
4.7 cor_pancancer_drug

Description

Calculate the correlation between target gene expression and anti-tumor drug sensitivity in multiple datasets.

Usage

cor_pancancer_drug(
  df,
  cor_method = "pearson",
  Target.pathway = c("Cell cycle")
)

Arguments

ArgumentDescription
dfThe expression data of the target gene in multiple datasets, obtained by the get_expr_data() function.
cor_methodMethod for correlation analysis, default "pearson".
Target.pathwayThe signaling pathways of anti-tumor drug targets, default "Cell cycle". Use "drug_info" to get the detailed information of these drugs.

Examples

target_data <- get_expr_data(datasets = c("LUAD_CPTAC_protein", "LSCC_CPTAC_protein"), genes = "STAT3")
results <- cor_pancancer_drug(df = target_data, Target.pathway = c("Cell cycle"))

4.9 viz_TvsN

Description

Visualizing the differential expression of mRNA/protein expression data between Tumor and Normal tissues in CPTAC database.

Usage

viz_TvsN(
  df,
  df_type = c("single", "multi_gene", "multi_set"),
  Show.P.value = TRUE,
  Show.P.label = TRUE,
  Method = "t.test",
  values = c("#00AFBB", "#FC4E07"),
  Show.n = TRUE,
  Show.n.location = "default"
)

Arguments

ArgumentDescription
dfGene/protein expression data obtained from get_expr_data().
df_typeThe type of expression data: "single", "multi_gene", or "multi_set".
Show.P.valueWhether to display the results of differential analysis, default TRUE.
Show.P.labelWhether to display significance markers for differential analysis, default TRUE.
MethodMethods of differential analysis, "t.test" or "limma", default "t.test".
valuesColor palette for normal and tumor groups. Default c("#00AFBB", "#FC4E07").
Show.nDisplay sample size.

Examples

expr_data <- get_expr_data(datasets = "LUAD_CPTAC_protein", genes = c("TP53"))
viz_TvsN(expr_data, df_type = "single")
viz_TvsN(expr_data, df_type = "single", Method = "limma")
4.10 viz_DEGs_volcano

Description

Plotting volcano plot for DEGs between tumor and normal samples in CPTAC datasets.

Usage

viz_DEGs_volcano(
  df,
  p.cut = 0.05,
  logFC.cut = 1,
  show.top = FALSE,
  show.labels = NULL
)

Arguments

ArgumentDescription
dfDEG results from get_DEGs_result() function.
p.cutNumeric. The cutoff for adjusted p-value to determine significance. Default is 0.05.
logFC.cutNumeric. The cutoff for log fold change to determine significance. Default is 1.
show.topLogical. If TRUE, labels the top upregulated and downregulated genes. Default is FALSE.
show.labelsCharacter vector. Specific gene labels to show. Default is NULL.

Examples

degs <- get_DEGs_result(dataset = "LUAD_CPTAC_protein", method = "t.test")
viz_DEGs_volcano(degs)
viz_DEGs_volcano(degs, p.cut = 0.01, logFC.cut = 2, show.top = TRUE)
4.11 viz_cor_heatmap

Description

Presenting correlation analysis results using heat maps based on ggplot2.

Usage

viz_cor_heatmap(r, p)

Arguments

ArgumentDescription
rThe correlation coefficient matrix r of the correlation analysis results obtained from cor_pancancer_genelist(), cor_pancancer_TIL(), and cor_pancancer_drug().
pThe p-value matrix p of the correlation analysis results.

Examples

target_data <- get_expr_data(datasets = c("LUAD_CPTAC_protein"), genes = "STAT3")
gene_list_data <- get_expr_data(datasets = c("LUAD_CPTAC_protein"), genes = c("TNS1", "TP53"))
results <- cor_pancancer_genelist(df = target_data, geneset_data = gene_list_data)
viz_cor_heatmap(results$r, results$p)
4.12 viz_corplot

Description

Scatter plot with sample size (n), correlation coefficient (r) and p value (p.value).

Usage

viz_corplot(
  data,
  a,
  b,
  method = "pearson",
  x_lab = " relative expression",
  y_lab = " relative expression"
)

Arguments

ArgumentDescription
dataA gene expression dataset with at least two genes included, rows represent samples, and columns represent gene expression in the matrix.
aGene A
bGene B
methodMethod for correlation analysis, "pearson" or "spearman".
x_labX-axis label.
y_labY-axis label.

Examples

expr_data <- get_expr_data(datasets = "LUAD_CPTAC_protein", genes = c("TP53", "TNS1"))
viz_corplot(expr_data, a = "TP53", b = "TNS1", method = "pearson")
